## 再次验收先看

历史批次是**环境中断记录，不是功能验收通过**。S03 的 40 项结果为：0 项完整通过、0 项已确认功能失败、8 项部分证据、24 项阻塞、8 项待 Android。档案整理没有启动 Unity、连接游戏、执行 GM、读取或修改 K1 正式仓库，也没有重跑下列脚本。

1. 先核对稳定的 Unity/配置环境、实际登录身份和测试服部署版本。历史发生重载及意外退出 Play，客户端工作区也发生变化；同一 Git HEAD 不能证明运行资源未变（GPA-E03）。
2. Editor 构建目标为 Android 仍不执行 `UNITY_ANDROID && !UNITY_EDITOR` 下的原生分支。Editor 的旧任务绑定不含新增隐藏任务，未收到隐藏任务不能证明能力过滤正确（GPA-P01、GPA-P02）。
3. 先用 [脚本说明](scripts/usage.md) 中的只读任务快照判断能否继续：历史 26 条任务中 23 条已领取、3 条已过期，没有 GoOn/Finish，不能覆盖推进、领奖、红点和倒计时。
4. 获得 UI 事件处理器返回 `clicked=true` 仍需截图、面板状态及正常协议回包确认实际打开。数据排序、文本配置或组件清单不能代替列表滚动与显示验收。
5. 下一轮需正常 `CpeTaskInfoReq/Ack`、`CpeTaskCfgsNtf`、真实任务变化及持久资产证据；历史没有完整协议原文，也没有账号级 CPE 重置/期限 GM 的已核实方法。历史许可及账号不随档案继承。
