# 功能名称：验收经验档案

填写时保留真实未知项及下一步，删除本段使用说明。创建于 `features/<featureId>/experience.md`；该功能的运行脚本及使用说明放在同目录下的 `scripts/`。路径相对实际档案目录解析；一个功能对应一个稳定 featureId 和目录。

| 字段 | 内容 |
|---|---|
| featureId | 项目与功能的稳定标识 |
| 名称 / 别名 | 正式名称、旧称、代码关键词 |
| 关联需求 / 分支 | 已核实的 Jira、需求标识和历史分支，仅作定位 |
| 档案更新时间 | 实际维护日期及时区 |
| 最近实际验证 | 日期、阶段、版本与来源；未知写未验证 |
| 维护源 / 在线地址 | 当前本地文件；未来迁移时填真实在线地址 |

## 再次验收先看

列出本功能有效的定位入口、关键前置、主要易漏分支、待复核项及脚本说明。注明历史结果不等于本轮验收结论。

## 预检后文档确认标记（documentBaseline）

按 [经验规则](../references/feature-experience.md) 填写。没有真实确认及回读证据时保持待复核，不沿用模板占位值。

| 字段 | 内容 |
|---|---|
| status | needs_review（待复核） |
| source | 原文档唯一来源/链接 |
| confirmedVersion | 已确认版本或内容哈希，未知留空 |
| confirmedAt / precheckRunId | 实际确认时间及时区、预检批次，未知留空 |
| currentVersion / checkedAt | 本次实际读取版本及核对时间，未读取注明未读取 |
| evidence | 预检确认、文档回读和当前版本核对证据 |
| reason / nextAction | 缺失依据及补证动作；已确认后可留空 |

再次验收先读取当前原文核对：一致时明确“当前文档已是预检确认后的版本”；变化仅重对齐受影响规则；不可读或缺依据时待复核。该标记不代表功能验收通过。
