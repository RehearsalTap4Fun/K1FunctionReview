# 验收时间节点与客户端路径

运行验收有两个**由用户指定的时间节点**：功能开发完成时验收和版本日验收。现有计划字段 `acceptanceMode` 沿用 `development` / `mainline_regression` 两个 ID，分别对应这两个节点；ID 不代表一定使用开发分支或主分支，不能按分支名或当前日期替用户选择。客户端路径默认包含 **Unity 验收和真机包验收**；用户明确限定为其中一条时，只执行该路径并将另一条标为本轮范围外：

| 用户指定的时间节点 | Unity 编辑器 | 真机安装包 |
|---|---|---|
| 功能开发完成时 | 按本轮详细验收范围实测 | 按同一范围在目标设备实测 |
| 版本日 | 按本轮版本日玩家体验范围实测 | 按同一范围在目标设备实测 |

同一节点所选路径各自记录前置、实际连接目标、断言结果和证据；两条路径都在范围内时可共享已核实相同的需求基线、转换产物和准备方法，不能用一条路径的观察代替另一条。只有本轮所选路径的必要范围都闭环，才能给该范围“通过”结论；单路径结论必须明确路径，不能称整个节点的双路径验收通过。所选路径尚未执行、缺包、缺环境或只有部分证据时，保留待验或阻塞并继续其他可执行路径。两个节点是不同批次，开发完成时的结果不能替代版本日结果。

## 每个时间节点的共同前置

以下流程只适用于实际运行验收；静态预检和用户单独委托的建服任务不自动触发客户端转换。

1. 从本轮需求、交接和实际仓库核对客户端与配置分支或提交、所选路径的目标平台或 Unity 项目版本、目标服务器实例/SID、应用类型和设备分配。未知的必要目标先查后问，不猜测分支或占用他人服务器。
2. **先转配置表和多语言。** 客户端 Jenkins 优先用 `K1_Build_Config_I18N_Mac`，显式传入本轮 `Client_Branch`、`Config_Branch`，同时设置 `Config=true`、`I18N=true`。该任务不可用或不适用于本轮时，核对参数和产物后再选 `K1_Build_Config_I18N` / `K1_Build_Config_I18N_v2`。`K1_Build_Config_I18N_Mac_Internal` 只供内部自动修复流程调用，不作为常规验收入口。同一节点的 Unity 与真机路径输入、版本和产物完全一致时，一次成功转换可供两条路径使用；不一致时分别转换并记录对应关系。版本日须使用该节点的新转换回执，不能拿开发完成时的旧回执代替。
3. 等待转换任务终态成功，核对构建号、实际输入分支/提交、日志与产物或发布位置。成功状态本身不能证明目标客户端已加载转换结果；失败、取消、产物不明或输入不符时先定位影响，不直接开始受影响路径的验收。重试或切换任务前核对是否已有写入，避免重复推送或覆盖产物。
4. **再为所选路径的每个客户端实例启动本轮专属服务器。** 按 [设备与测试服隔离](device-server-isolation.md) 确认分配，按 [Jenkins 环境准备](jenkins-test-environment.md) 执行已授权的备份、导入和部署。开测前分别核对服务器就绪、代码/配置版本、实例身份和 SID，并确认转换结果已在对应客户端及运行环境生效。默认每个客户端实例独占服务器；共享例外只按隔离规则处理。接续同一节点同一批次且输入版本未变时，已成功的转换回执和仍有效的本轮专属服可经复核后沿用。
5. 让所选路径的客户端分别登录各自专属服，核对玩家、SID、客户端/服务器/配置版本及多语言资源；将转换、部署和登录证据保存到本轮环境记录。转换与部署就绪只满足前置条件，不代表业务验收通过。

配置/多语言**转换任务**与玩家可见界面的英、俄、阿**实际显示检查**是两步；转换成功不能替代各路径必要的切换语言、截图和界面断言。

## Unity 路径

在对应版本 Unity 项目中确认已加载本轮转换产物与多语言资源，进入 Play 模式并登录本路径专属服。记录项目/客户端版本、资源版本、Unity 实例和实际登录目标，按本节点范围执行断言。Unity 观察不能证明真机触控、安全区或原生 SDK 表现；这些结论由真机路径提供证据。

## 真机包路径

按目标平台构建真实设备安装包，确认包使用本轮转换结果。目标平台有适用的 Mac 出包任务时优先使用，例如 Android 的 `K1_Android_Build_FromMac`；先核对现行任务参数、渠道和产物，其他平台按实际可用任务选择。Android 依照 [Mac 出包通知、APK 下载与真机安装](android-package-install.md) 核对 Jenkins、钉钉通知、下载文件、ADB 安装和实际登录目标；记录包构建号、客户端版本、渠道与安装设备，按本节点范围执行断言并保留触控、安全区、原生 SDK 等适用证据。
