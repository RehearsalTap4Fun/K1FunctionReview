## 一、核心设计模式

### 模式1：技能等级分段验证

**适用于**：有等级成长、不同等级解锁不同效果的技能系统

**分段结构**：
```
0-4级（基础效果）→ 5-9级（效果1解锁）→ 10-14级（效果2解锁）→ 15-19级（效果3解锁）→ 20级（满级特殊效果）
```

**每段验证点**：
1. 技能界面显示 → 成长栏正确显示当前已解锁效果
2. 提示栏 → 显示下一级即将解锁效果
3. 技能总览气泡 → 已解锁效果显示✔，未解锁置灰
4. 战斗验证 → 新效果正确生效
5. 同段遍历 → "技能效果均与上方一致，buff数值正确增加"

### 模式2：被动技能三态验证

**适用于**：可解锁、可进阶的技能系统

**三态结构**：
```
未解锁 → 初始解锁 → 进阶（二选一）
```

**验证流程**：
| 状态 | 验证点 |
|------|--------|
| 未解锁 | 携带出战，属性不会提升 |
| 初始解锁 | 属性提升x%，触发条件，buff持续时间 |
| 进阶后 | 属性提升至y%，额外效果验证 |
| 升级 | "技能效果均与上方一致，buff数值正确增加" |

### 模式3：计数机制验证

**适用于**：层数触发、概率触发的机制

**验证结构**：
```
1. 触发条件（普攻/被普攻/技能）
2. 触发概率（50%/100%）
3. 计数层数（达到N层触发效果）
4. 效果持续时间（M回合）
5. 计数重置时机（何时可再次触发）
6. 多目标/多单位场景
7. 战斗结束后计数是否保留
```

**典型用例**：
```
| 第n回合，印记层数达到y | 所需印记数正确 |
| | n回合机甲防御力额外提升z |
| | n+1回合机甲防御力额外提升z |
| | n+2回合机甲防御力额外提升z |
| | n+3回合机甲防御力不再额外提升 |
```

### 模式4：条件触发机制验证

**适用于**：特定条件触发的效果（如现身增怒）

**验证结构**：
```
触发场景 × CD机制 × 边界条件
```

**触发场景遍历**：
| 场景 | 预期 | 备注 |
|------|------|------|
| 从主城出现3s内攻击 | 获得额外怒气 | 基准场景 |
| 离开采集点建筑 | 与主城出现一致 | |
| 离开遗迹建筑 | 与主城出现一致 | |
| 脱离隐身 | 与主城出现一致 | |
| 脱离炮塔形态 | 不会增加怒气 | 特殊场景 |
| 驻防进入战斗 | 获得额外怒气 | |

**CD验证**：
- CD内再次触发 → 不会获得
- CD后再次触发 → 可以获得

### 模式5：buff持续时间验证

**适用于**：有持续时间的增益/减益效果

**验证结构**：
```
| 第n回合触发 | 效果生效 |
| n+1回合 | 效果持续 |
| n+2回合 | 效果持续 |
| n+3回合 | 效果消失 |
```

**关键点**：
- 精确验证每一回合的效果状态
- 验证效果消失时机

### 模式6：多单位交互验证

**适用于**：涉及多个玩家/多个机甲的场景

**验证矩阵**：
| 场景 | 验证点 |
|------|--------|
| A携带机甲 vs B携带机甲 | 各自计数独立 |
| AB同时攻击C | 各自效果独立生效 |
| A机甲死亡后 | B机甲效果不受影响 |
| 双方机甲同类型 | 效果不会互相干扰 |

## 二、用例设计技巧

### 1. 分段遍历简化

**目的**：避免重复验证同质化内容

**用法**：
```
| 遍历鳄鱼机甲主动技能6-9级 | 主动技能增益对应效果均不会改变，与上方一致 |
| | 对应技能buff数值正确增加，与当前技能等级对应一致 |
```

### 2. 负向验证

**目的**：验证"不应该触发"的场景

**用法**：
```
| 未解锁技能 | 属性不会提升 |
| 条件未达成 | 效果不会触发 |
| 非触发条件操作 | 不会施加效果 |
```

### 3. 配置关联标注

**目的**：明确数值验证的配置来源

**用法**：
```
| 检查点 | 预期结果 | 备注 |
|--------|----------|------|
| 机甲战斗力 | 正确显示 | 4002 4003 A_ARR_status字段 |
| 技能成长效果 | 符合配置 | 4003 C_ARR_skill_data |
```

### 4. 场景覆盖标准化

**目的**：确保所有战斗场景都覆盖

**标准场景列表**：
- 野外PVP
- 野外PVE（野怪）
- 围剿变异猴
- 精英竞技场
- 霍格博士的复仇
- 机甲战场
- 好友切磋
- 火车竞赛
- 攻击敌方基地
- 攻击敌方占领建筑

**简化写法**：
```
| 在火车竞赛内，携带机甲参战 | 结果和上方一致 |
| 在围剿变异猴内，携带机甲参战 | |
| 精英竞技场内，携带机甲参战 | |
...
```

## 三、机甲系统用例模板

### 1. 解锁模块（~30条）

```
1. 入口验证
   - 未解锁机甲列表显示
   - 头像、进度、品质颜色
   
2. 界面元素验证
   - 模型显示
   - 三个部位解锁任务进度
   - 机甲信息（昵称、简述、定位）
   - 解锁任务列表
   
3. 解锁任务验证
   - 任务跳转
   - 任务进度增加
   - 部位进度增加
   
4. 激活验证
   - 达成条件后激活
   - 入场动画/idle动画
   - 机甲信息列表（耐久、战斗力、属性、技能）
```

### 2. 养成模块（~60条）

```
1. 等级升级
   - 升级界面

   - 满级限制
   
2. 自由属性点
   - 分配界面

3. 技能升级
   - 升级界面
```

## 四、关键验证点总结

### 机甲系统必测项

| 类别 | 验证点 |
|------|--------|
| 解锁 | 任务进度、激活流程、资源显示 |
| 等级 | 经验消耗、属性增长、满级限制 |
| 技能 | 等级效果、buff数值、持续时间 |
| 计数 | 触发概率、层数阈值、重置时机 |
| 战斗 | 伤害系数、buff生效、多单位场景 |
| 场景 | 各战斗模式、LOD切换、模型动画 |

### 高风险验证点

| 风险点 | 验证重点 |
|--------|----------|
| buff持续时间 | 精确到每一回合验证 |
| 计数重置 | n+7回合内不触发，n+8回合可触发 |
| 多机甲交互 | 各自效果独立，不互相干扰 |
| 机甲死亡后 | 已施加的效果是否继续 |
| 数值叠加 | 多个满级被动的叠加计算 |
