### 用例编写特点

1. **双编号系统**：主系列GCLB_xxx + 补充系列LJZ_xxx
2. **特殊支付场景**：俄罗斯VPN支付验证（LJZ_005-006）
3. **老版本兼容**：详细的服务器/客户端更新场景
4. **两阶段活动**：第一阶段和第二阶段的完整验证
5. **顺序解锁**：前置奖励未领取时的限制验证
