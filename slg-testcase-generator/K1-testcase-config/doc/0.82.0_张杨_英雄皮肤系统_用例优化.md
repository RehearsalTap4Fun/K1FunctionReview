## 用例设计总结

> **用例设计四原则**：
> 1. **描述/提炼准确**：给出明确的规则定义，后面直接沿用定义
> 2. **环环相扣**：尽量按测试顺序检查
> 3. **拆解再重组**：找到最合适的模块（简单的单规则验证完，再做组合）
> 4. **清晰引导**：无法完全做到第2/3点的，给出清晰的引导提示（参考哪里、哪里可以合并检查）
