## 三、用例设计亮点

### 1. 权限矩阵验证法

用例系统性地覆盖了所有权限组合：

| 条件组合 | 帮派等级 | 玩家等级 | 预期 |
|----------|:--------:|:--------:|------|
| 未解锁无权限 | <x | R4以下 | 入口不显示 |
| 未解锁有权限 | <x | R4及以上 | 入口不显示 |
| 已解锁无权限 | ≥x | R4以下 | 入口不显示 |
| 已解锁有权限 | ≥x | R4及以上 | 入口显示 |
| 降级场景 | x→x-1 | R4及以上 | 入口消失 |

**示例用例**：
- LMZJ_001: 帮派等级<x级，帮派R4及以上玩家 → 入口不显示
- LMZJ_005: 帮派等级≥x级，帮派R4及以上玩家 → 入口显示
- LMZJ_009: 帮派等级从x级降级为x-1级 → 入口消失

### 2. 位置类型遍历法

用例覆盖了所有位置类型：

**可操作位置**：
- ✅ 最外圈可传送区域
- ✅ 内圈帮派/氏族领地
- ✅ 树林

**不可操作位置**：
- ❌ 未联通区域
- ❌ 其他帮派领地
- ❌ 非帮派领地（内圈）
- ❌ 中立建筑领地
- ❌ 装饰建筑区域
- ❌ 未解锁区域

**示例用例**：
- LMZJ_093: 外圈层未联通区域 → 定位光标显示红色
- LMZJ_106: 其他帮派领地 → 表现同未联通区域一致
- LMZJ_118: 树林位置 → 可正确发起召集

## 六、可复用的用例设计模式

### 模式1：条件矩阵法

```
1. 列出所有条件维度（如：帮派等级、玩家权限）
2. 生成所有组合（2×2=4种）
3. 补充状态变化场景（升级、降级）
```

### 模式2：位置分类法

```
1. 可操作位置：最外圈、己方领地、特殊地形
2. 不可操作位置：未联通、他方领地、中立建筑、装饰建筑、未解锁
3. 边界位置：位置被占、位置失效
```

### 模式3：入口引用法

```
1. 选定基准入口，完整验证
2. 其他入口使用"表现同xxx一致"引用
3. 补充交叉验证用例
```

### 模式4：状态转换法

```
1. 列出所有可能的状态变化（退出、加入、权限变化）
2. 验证变化前后功能表现
3. 验证变化过程中的中间状态
```

### 模式5：时机边界法

```
1. 操作过程中等待条件变化
2. 操作即将完成时条件变化
3. 多人同时操作的并发场景
```
