## 二、用例设计分析

### 1. 技能等级分段验证模式

**主动技能分段**：
- 0-4级（基础效果）
- 5-9级（攻击提升解锁）
- 10-14级（防御提升解锁）
- 15-19级（生命提升解锁）
- 20级（满级特殊效果）

**每段验证结构**：
```
1. 查看技能界面 → 技能成长栏显示正确
2. 提示栏显示下一级解锁效果
3. 技能总览气泡显示已解锁/未解锁
4. 战斗验证 → 效果生效
5. 遍历同段等级 → "技能效果均与上方一致，buff数值正确增加"
```

### 2. 被动技能三态验证模式

**技能状态**：
- 未解锁状态
- 初始被动技能（解锁后）
- 进阶技能1-1/1-2（二选一）

**每态验证结构**：
```
1. 未解锁 → 携带出战 → 属性不会提升
2. 初始解锁 → 属性提升x% → 触发条件验证 → buff持续时间
3. 进阶后 → 属性提升至y% → 额外效果验证
4. 升级验证 → "技能效果均与上方一致，buff数值正确增加"
```

### 3. 计数机制验证模式

**计数流程**：
```
1. 触发条件验证（普攻/被普攻）
2. 触发概率验证（50%）
3. 计数层数验证（3层触发）
4. 效果持续时间（3回合）
5. 计数重置时机（n+7回合内不再触发，n+8回合可再次触发）
6. 多目标/多机甲场景
7. 战斗结束后计数不保留
```

### 4. 现身增怒机制验证

**触发场景**：
```
1. 从主城中出现 → 3s内攻击 → 获得额外怒气
2. 离开采集点建筑 → 同上
3. 离开遗迹建筑 → 同上
4. 脱离隐身 → 同上（有bug：F）
5. 脱离炮塔形态 → 不会增加怒气
6. 驻防进入战斗 → 获得额外怒气
7. CD验证 → 20s内再次触发不会获得
8. CD后验证 → 20s后可再次获得
```

### 5. 场景覆盖模式

**战斗场景遍历**：
- 攻击野怪
- 围剿变异猴
- 精英竞技场
- 霍格博士的复仇
- 机甲战场
- 好友切磋
- 攻击敌方基地
- 攻击敌方占领建筑
- 火车竞赛

### 6. 流血效果验证

**流血机制**：
```
1. 基础流血伤害（50系数）
2. 满级被动加成（+3/+10系数每层）
3. 持续回合验证（14回合）
4. 结束后不再受到伤害
5. 多机甲叠加（AB同时释放，各自独立计算）
6. 机甲死亡后流血是否继续
7. 技能伤害提升对流血的影响
```

## 三、用例设计技巧

### 1. 分段遍历简化

```
| 遍历鳄鱼机甲主动技能6-9级 | 主动技能增益对应效果均不会改变，与上方一致 |
| | 对应技能buff数值正确增加，与当前技能等级对应一致 |
```

### 2. 条件-效果-持续时间验证结构

```
| 第n回合，印记层数达到y | 所需印记数正确 |
| | n回合机甲防御力额外提升z |
| | n+1回合机甲防御力额外提升z |
| | n+2回合机甲防御力额外提升z |
| | n+3回合机甲防御力不再额外提升 |
```

### 3. 配置关联标注

```
| 检查点 | 配置表 |
|--------|--------|
| 机甲耐久力进度条 | 4002表 |
| 机甲战斗力显示 | 4002 4003 A_ARR_status字段 |
| 机甲四个基础属性 | 4009表 A_ARR_soldier_stat |
| 技能成长效果 | 4003 C_ARR_skill_data |
```

### 4. 多机甲交互验证

```
| 携带蝎子的部队与携带鳄鱼的部队进行战斗 | 蝎子的自我计数正确 |
| | 蝎子对敌人的计数正确 |
| | 鳄鱼对自我的计数正确 |
| | 鳄鱼对敌人的计数正确 |
```

### 5. 负向验证

```
| 鳄鱼机甲还未解锁被动技能1 | 鳄鱼机甲防御力不会有额外提升 |
| 印记层数未达到y层 | 不会提高防御力 |
| 敌方对我方反击 | 不会对我方施加印记 |
| 敌方对我方释放主动技能 | 不会对我方施加印记 |
```
