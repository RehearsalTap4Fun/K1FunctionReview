## 二、系统规则

### 1.2.1 功能大致介绍

玩家可以通过穿戴斗士皮肤所包含的一系列内容满足自身对于外观、自身独特性的追求。

斗士皮肤属于收藏内容，拥有一定的鉴赏积分，可以作用于当前"美观度徽章"系统。

**斗士皮肤包含以下内容**：
1. 玩家使用的斗士头像
2. 斗士染色（参考机甲皮肤系统）
3. 斗士皮肤（新建模型）
4. 指挥官信息背景图像

### 1.2.2 斗士皮肤系统规则介绍

#### 1. 斗士皮肤系统开启

- 斗士皮肤系统开启将在功能更新后同步至所有可开放活动服务器，具体schema由运营同学确定
- 斗士皮肤系统入口设计在斗士界面，同机甲皮肤系统，名称为"涂装"

#### 2. 斗士皮肤系统介绍

**皮肤等级**

斗士皮肤包含不同级别的获取难度，并对应获取难度的稀有等级。

| 稀有度 | 动态效果 | 大地图模型 | 颜色 | 配套 |
|--------|----------|------------|------|------|
| 默认皮肤 | 无 | 初始模型 | 不改变 | 无 |
| 染色皮肤 | 无 | 初始模型 | 单一颜色 | 无 |
| 稀有皮肤 | 无 | 新模型 | 新配色 | 头像，指挥官背景 |
| 传奇皮肤 | 有 | 新模型 | 科技/高级外观 | 头像，背景，额外表现 |

**皮肤属性**

- 玩家装备皮肤后获得一定属性
- 属性生效与玩家使用的斗士在部队中是主将还是副将无关
- 玩家获得的属性是斗士的使用属性，类似斗士雕像
- 皮肤提供的buff不是常驻的，只有当玩家使用对应斗士时才会生效
- 皮肤属性是使用属性，因此相关属性不会显示在增益统计中
- 通过1211buff配置进行实现

**皮肤佩戴**

- 由于皮肤佩戴涉及到玩家本身战斗属性的改变，因此玩家只能在对应斗士在主城内时，进行皮肤的穿戴/脱下/更换
- 若当前玩家操作不合法（部队出征在外进行穿戴）则报错

**客户端相关**

当玩家穿戴一款皮肤后，玩家的外观内容在下次出征后会被统一替换，可以被其他玩家浏览到改变内容。

统一替换外观内容包含：
1. 大地图头像
2. 编队界面模型
3. 英雄选择界面（包含参谋助战头像，模型，半身像）
4. 大地图模型
5. 穿戴皮肤后的战报内头像

**注意**：
- 原先的战报中的头像保持玩家当时穿戴皮肤时的样子，不需要动态改变
- 皮肤对应指挥官头像与指挥官背景的选择，不随着穿戴皮肤后进行同步改变

**皮肤获取**

玩家根据相关运营活动规则获得皮肤，相关调研活动产出如下：
- BP：低级皮肤产出
- 商店直购
- 购买后完成任务（顶级皮肤）
- 大富翁（拆分本体，指挥官背景，行军播报）

皮肤获取途径配置1168、1153中具体获取活动

**可选皮肤绑定外观**：
- 战报内特殊立绘
- 特殊头像框
- 登录界面动态主题

## 三、界面详述

### 1.3.1 斗士界面相关

#### 1. 入口逻辑

斗士展示界面新增"涂装"入口

涂装显示有两种状态：
1. 当对应斗士还没有皮肤时，入口被隐藏
2. 当对应斗士有皮肤推出时，显示入口

#### 2. 皮肤界面逻辑

斗士界面参考机甲界面
