## 二、规则内容

### 2.1 功能大致介绍

- P2_ux效果图: https://drive.google.com/drive/folders/193tTyEMU1I0FaPMLzpl-c98Ag6UNax1u
- P2逻辑流程图: https://drive.google.com/file/d/1vEKT8nZB7Cuix120X-oMFnnQCnm0V1c1/view

此系统主要玩法为图鉴卡片收集，系统内有多种集卡图鉴，玩家通过特殊途径或者玩家间互相交换来收集卡片。

- 每种图鉴里有特定数量主题卡，每种主题卡有特定数量子卡
- 所有子卡收集完成后，此主题卡为收集完成状态
- 所有主题卡收集完成后，此图鉴为收集完成状态

系统内除主要界面外，有3种核心功能：
- **互赠**：玩家间通过许愿行为交换卡片
- **回收**：回收一些重复卡片，换取特定货币
- **卡包**：使用卡包可以获得随机卡片

### 2.2 功能基本规则

#### 2.2.1 功能解锁规则

服务器暂定3天且玩家聊天系统解锁，解锁功能
- 1768012200 集卡功能解锁 unlock_card_gallary_book
- 信息界面入口、建筑入口、商店入口、通知推送保持解锁一致

#### 2.2.2 图鉴基础规则

**1) 层级规则**

| 类型 | 定义 | 数量 |
|------|------|------|
| 图鉴 | 一个独立的收集册，包含多个相关的主题 | 共3组 |
| 主题卡 | 图鉴内的主要收集目标 | 每组16个 |
| 主题子卡 | 主题卡下的具体收集项 | 每个主题卡9张子卡 |

**2) 图鉴规则**

- 各个图鉴相互独立，可通过页签切换不同图鉴
- 有系统图鉴和活动图鉴类型
  - 系统图鉴：通过常规服务器schema或时间解锁
  - 活动图鉴：通过特定运营活动解锁
- 图鉴有过期规则：
  - 系统图鉴：新图鉴出来后，旧的图鉴自动过期（过期图鉴只是无法通过常规途径获取，但回收、许愿、开卡包都可以）
  - 活动图鉴：跟随运营活动时间，活动时间结束则为过期状态
- 图鉴收集完成后，可以领取成就奖励，各个图鉴成就奖励独立
- 过期卡册也可以正常获得卡片，集齐后可以兑奖

**3) 主题卡规则**

- 每个主题卡都有名称、图片、收集进度
- 完成所有主题子卡收集后，该主题卡为收集完成状态
- **主题卡解锁**：
  - 部分主题卡需要根据当前图册三星卡片的收集数量做判断解锁
  - 每个卡册收集判断数量独立
  - 若某主题卡未解锁，则此主题卡中的卡片无法通过卡包开出
  - 客户端表现：未解锁主题卡压暗显示，显示"收集3/5张3星卡片解锁此主题"

**4) 主题子卡规则**

- 每张子卡都有名称、图片、品质、回收价格和归属主题属性
- 普通子卡可以进行捐赠，特殊子卡无法许愿和捐赠
- 通过特殊途径、玩家互赠和卡包开取获取子卡
- 获得卡片后自动点亮相应的子卡，且为所属主题收集进度加1
- 子卡品质分为1星卡、2星卡、3星卡和特殊2/3星卡

#### 2.2.3 许愿规则

玩家除了通过常规途径获取卡片外，还可以通过【许愿】功能交换卡片。

**1) 许愿限制**

- 玩家每次同时只能存在一种许愿卡片，每天仅可被捐赠一次
- 玩家在未获得捐赠时，可以手动切换许愿卡片
- 每天UTC 0点会把玩家的许愿清除
- 玩家可以将许愿卡片分享到聊天频道
- 同联盟的玩家可以直接在许愿界面看到其余联盟成员的许愿内容

**2) 捐赠规则**

- 玩家仅可捐赠自己多余重复的卡片（某张卡只有1张时无法捐赠）
- 部分特殊卡不能被捐赠
- 捐赠后根据卡片品质获得一定数量帮派荣誉币，每天有上限
- 玩家捐赠后会自动发送私聊消息
- 被捐献人会自动给捐献人点赞

**3) 获赠历史**

- 获得赠送卡片后会留下历史记录
- 历史记录会记录获赠时间与内容，也可进行回赠操作
- 超过7天的记录清除

#### 2.2.4 回收规则

- 重复的卡片可以被系统回收，每张卡有回收价格配置
- 回收获得的货币可以用来购买卡包商店中的商品

#### 2.2.5 卡包规则

**1) 卡包定义**

- 卡包是除许愿捐赠外获取卡片的主要途径
- 卡包与图册一一绑定，相应卡包只能开启本图册的卡片
- 卡包会在部分活跃途径投放，也会上架集卡商店售卖
- 卡包会根据图鉴的状态自动解锁或过期消失

**2) 卡包类型**

| 类型 | 说明 |
|------|------|
| 纯星级卡包 | 只能开出特定星级卡 |
| 随机星级卡包 | 概率开出不同星级 |
| 特定星级自选卡 | 在指定范围内选择 |
| 指定主题卡内随机 | 在特定主题内随机 |
| 未拥有星级卡 | 优先掉落未拥有的卡 |

**3) 卡包商店**

- 新增商店跟随系统同时解锁
- 两种刷新规则：特定数量买完消失 / 购买次数定时重置
- 卡包会根据图鉴状态自动解锁或过期消失

### 2.3 卡包投放规则

- 卡包基本通过活跃任务或付费购买礼包获取
- 新图鉴出来后要替换新的卡包
- 旧卡包会上架图鉴商店给玩家后续收集

## 三、界面内容

### 3.1 功能入口及推送

**入口**：
- 信息界面入口（右上角）
- 建筑入口（放置在猩球里程碑 11187101）

**推送通知**：
- 每天初始登录
- 获得他人赠送
- 解锁新卡集

**红点通知**：
1. 【许愿互赠】按钮：每天未许愿时显示红点
2. 新卡包上线或每周重置卡包次数后显示红点
3. 有奖励未领取时显示红点

### 3.2 图鉴主界面

**左侧**：各图鉴页签，可点击切换

**默认选中逻辑**：
- 优先选中display_order排序高的图鉴
- 若高id图鉴收集完成，选择第二高且未收集的
- 若全部收集完成，默认选择高id图鉴

**页签状态**：
| 状态 | 表现 |
|------|------|
| 选中 | 正常表现 |
| 未选中 | 透明度低 |
| 限时 | 页签上方显示倒计时 |
| 限时结束 | 过期状态 |
| 已收集完成 | 页签显示√ |
| 新出图鉴 | 页签显示"NEW" |

**中间**：显示收集进度、各主题卡收集情况
