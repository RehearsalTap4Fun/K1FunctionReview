### 用例编写特点

1. **功能模块空值继承**：同一功能模块下的用例，功能模块和检查点列使用空值继承
2. **操作步骤复用**：同一操作步骤可对应多条预期结果
3. **配置表标注**：备注列标注相关配置表ID（如2011、2013、2030）
4. **遍历合并**：使用"遍历"检查点合并同质化验证
5. **通用模块复用**：异常、用户体验、本地化、兼容性等通用模块可跨功能复用
