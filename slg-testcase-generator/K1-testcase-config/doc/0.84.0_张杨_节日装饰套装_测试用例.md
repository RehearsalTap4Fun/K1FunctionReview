## 用例编写模式分析（对比沙滩寻宝）

### 1. 功能类型差异

**沙滩寻宝（Type D）**：运营活动，核心是操作流程
**节日装饰套装（Type A）**：系统功能，核心是状态管理

### 2. 检查点深度差异

**装饰套装的状态检查更细致**：

```
| ZSTZ_045 | 已获得 | 1.第一个系列内有装饰a、b\n2.a的初始排序非首位\n3.获得a装饰 | 封面内的当前拥有装饰数量刷新为1 |
| ZSTZ_046 | | | a装饰在第一个系列内首位显示，其他装饰卡片依次往后挪一位 |
| ZSTZ_047 | | | a装饰高亮显示，其他装饰卡片状态不变 |
| ZSTZ_048 | | | a装饰卡片的星级只点亮一颗星 |
```

### 3. 进度验证模式

**临界值检查**（N-1 → N）：
```
| ZSTZ_078 | 临界检查 | 第一系列总星级达到N-1 | 礼盒icon不会有发光效果 |
| ZSTZ_079 | | 点击礼盒icon进入成就奖励弹窗 | 计数刷新为N-1 |

```

### 4. 增益生效验证

**多层次验证buff生效**：
1. 弹窗内数值变化
2. 增益详情界面

```

| ZSTZ_101 | | 3.实际游戏中使用buff场景检查 | 第一档成就奖励buff正确生效，数值正确 |
```
