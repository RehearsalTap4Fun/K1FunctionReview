# 红色英雄系统（Red Hero System）

> 基于1500条人工用例深度分析提取的系统知识

---

## 一、系统概述

红色英雄是最高品质的英雄类型，通过**共享机制**继承其他橙色英雄的等级、星级、技能和天赋。

### 核心概念

| 概念 | 说明 |
|------|------|
| **共享** | 红色英雄选择一个橙色英雄作为共享目标，继承其属性 |
| **槽位** | 4个技能槽位，控制共享技能的生效等级上限 |
| **终极技能** | 4个槽位全满级后解锁的特殊技能 |
| **共享天赋** | 继承共享英雄的天赋树，需要激活点数激活 |
| **激活点数** | 消耗红色英雄碎片购买，用于激活共享天赋树 |

## 二、条件制约关系（核心规则）

### 技能等级 vs 槽位等级

这是红色英雄系统最核心的制约关系，**必须穷举所有情况**：

| 条件 | 显示 | 实际生效 | 用例数 |
|------|------|----------|:------:|
| 技能等级 > 槽位等级 | 红色+向下箭头 | 槽位等级 | 3条 |
| 技能等级 = 槽位等级 | 白色 | 技能等级 | 3条 |
| 技能等级 < 槽位等级 | 绿色 | 技能等级 | 3条 |
| 技能未解锁 | 置灰不显示等级 | 不生效 | 3条 |

### 升级后联动变化

升级槽位/技能后，必须检查关联变化：

```
升级槽位后：
├─ 依旧小于技能等级 → 弹槽位升级弹窗，不弹技能升级弹窗，颜色仍红色
├─ 等于技能等级 → 弹槽位升级弹窗，颜色刷新为白色
└─ 大于技能等级 → 弹槽位升级弹窗，颜色刷新为绿色

升级技能后：
├─ 依旧小于槽位等级 → 不弹弹窗，颜色仍绿色
├─ 等于槽位等级 → 不弹弹窗，颜色刷新为白色
└─ 大于槽位等级 → 不弹弹窗，颜色刷新为红色+向下箭头
```

## 三、共享机制验证点

### 共享成功后检查清单

```
共享成功弹窗：
├─ 横幅显示"共享成功"
├─ 两个头像+链接效果
├─ 头像底色与品质一致
├─ 两个头像右下角显示共享英雄等级
└─ 底部提示文本

共享技能模块：
├─ 问号图标刷新为共享英雄的4个技能图标
├─ 每个技能图标的样式、排序与共享英雄一致
├─ 每个技能图标顶部显示槽位等级（初始1级）
├─ 未解锁的技能图标置灰显示
└─ 底部计数为4/20

英雄展示模块：
├─ 模型后方虚化猴子出现光效
├─ 模型下方显示共享英雄的等级
├─ 等级进度条与共享英雄一致
└─ 星级与共享英雄一致

天赋模块：
├─ 问号图标刷新为共享英雄的3个天赋技能图标
├─ 每个技能图标的样式、排序、进度与共享英雄一致
├─ 所有技能图标初始置灰显示
└─ 底部计数为0/3

共享栏：
├─ 共享英雄位置显示头像
├─ 两个头像之间链接有光效
├─ 共享英雄头像右侧显示切换按钮
└─ 提示文本刷新为"当前共享斗士：xxx"，字体颜色黄色
```

### 切换/放弃共享

```
切换共享英雄：
├─ 二次确认弹窗（8条）
├─ 切换后各界面数据刷新（6条）
├─ 切换后实际生效验证（4条）
├─ 槽位等级不变
├─ 终极技能等级不变
└─ 激活点数不变

放弃共享英雄：
├─ 二次确认弹窗（8条）
├─ 放弃后界面重置为未共享状态
├─ 共享天赋树状态重置
└─ 终极技能仍生效
```

## 五、战力计算

### 战力来源

| 来源 | 说明 | 验证方法 |
|------|------|----------|
| 基础战力 | 一星一级战力 | 获得时验证 |
| 终极技能战力 | 各等级独立验证 | 遍历1-5级 |
| 共享技能战力 | 取min(技能等级, 槽位等级) | 解锁/升级时验证 |
| 共享天赋战力 | 激活的天赋树buff+天赋技能 | 激活时验证 |

### 战力验证规则

1. **分拆验证**：每种战力来源独立验证
2. **叠加验证**：多种来源同时存在时验证总和
3. **切换验证**：切换共享英雄时验证增减
4. **放弃验证**：放弃共享时验证减少
5. **位置验证**：总战力不会增加（只增加英雄战力）

```

├─ 顶部红色英雄评级
├─ 增益汇总数据（终极技能+共享技能+天赋+天赋技能）

详情模式：
├─ 红色英雄名称前方兵种类型icon与共享英雄一致

└─ 点击天赋技能图标 → 弹出详情气泡
```

### 战报检查

```
战斗日志页：
├─ 显示共享主、被动技能释放文本
├─ 显示终极技能释放文本
├─ 主动技能释放回合显示释放图标
├─ 点击技能文本 → 弹出技能详情气泡
└─ 气泡内容正确

战报详情页：
├─ 不会显示专属技能（未解锁时）
├─ 原本主将技能和天赋图标位置显示共享主、被动技能图标
├─ 图标左上角显示文本"共享"
└─ 技能图标可点击查看详情
```

## 八、红点规则

| 红点类型 | 触发条件 | 消失条件 |
|----------|----------|----------|
| 未共享红点 | 红色英雄未共享 | 共享任意英雄 |
| 槽位升级红点 | 有足够碎片升级 | 升级至无法继续升级 |
| 共享天赋红点 | 获得激活点数 | 使用完激活点数 |
