# 战车系统

> 提取自：新战车（反战车战车）人工用例

---

## 一、系统概述

### 战车品质
| 品质 | 颜色 | 稀有度标签 |
|------|------|------------|
| 蓝色 | 蓝 | 稀有 |
| 紫色 | 紫 | 史诗 |
| 橙色 | 橙 | 传说 |

### 核心概念
- **战车**：可搭载多个部队的编队单位，占用3个行军队列
- **舱位**：战车内的部队槽位，每个舱位有独立限定兵种
- **战车buff**：战车特有的增益效果，需购买礼包解锁
- **槽位等级**：每个舱位可独立升级，提升buff效果
- **战车特性**：部分战车有特殊战斗机制（如反战车攻击顺序）

## 二、基本规则

### 战车解锁
- 消耗礼包解锁（付费）
- 解锁后显示在战车列表
- 战车默认品质由配置决定

### 战车养成
| 养成项 | 消耗资源 | 特点 |
|--------|----------|------|
| 槽位等级 | 升级材料A/突破材料B | 每个槽位独立升级 |
| 战车buff | 礼包解锁 | 解锁后永久生效 |
| 舱位升级解锁 | 礼包购买 | 2、3号舱需购买解锁升级功能 |

### 战车槽位
| 槽位 | 默认状态 | 升级要求 |
|------|----------|----------|
| 1号舱 | 可直接升级 | 无 |
| 2号舱 | 需购买礼包 | 购买升级解锁礼包 |
| 3号舱 | 需购买礼包 | 购买升级解锁礼包 |

### 部队容量
```
战车总容量 = Σ(各舱位上阵部队容量)
单舱容量 = 主将容量 + 副将容量 + 其他加成
```

## 三、与其他系统的交互

### 1. 派兵系统
```
战车派兵限制：
- 每个舱位有限定兵种（打击手/飙车族/射击手等）
- 已在其他战车的英雄/机甲/部队不能重复选择
- 已出城的部队/英雄/机甲不能选择
- 战车占用3个行军队列

存档/取档：
- 支持存档和取档功能
- 存档内队列若有英雄/机甲/部队在城外，无法读取
```

### 2. 战斗系统
```
普通战车：
- 攻击顺序：舱位1→舱位2→舱位3
- 受击顺序：舱位1→舱位2→舱位3

反战车战车（干扰坦克特性）：
- 攻击敌方战车顺序：舱位3→舱位2→舱位1
- 己方受击顺序：舱位1→舱位2→舱位3
- 攻击普通部队时无此特性

承伤规则：
- 首个承伤部队：舱位1
- 承伤顺序：舱位1→舱位2→舱位3
```

### 3. 采集系统
```
战车采集规则：
- 战车到达采集点后模型消失
- 按舱位顺序依次采集（1→2→3）
- 显示的采集速度为第一个舱位部队速度
- 实际采集量为三个部队总和
- 采集中被攻击会中断采集
```

### 4. 集结系统
```
集结战车可发起/加入集结
反战车战车不能增援/加入集结
战报显示：按舱位1、2、3排序显示英雄头像
```

### 5. 跨服系统
```
kvk内：
- 可购买战车解锁/升级礼包
- 技能效果与原服一致
- 回到原服后正常使用

边境战斗：
- 战车可在边境刷怪/采集
- 龙卷风范围内战车会被冰冻
```

## 四、常见验证点

### 战车列表验证
```
□ 战车头像正确显示
□ 品质背景颜色正确
□ 战车名称显示正确
□ 解锁/未解锁状态正确
□ 解锁礼包价格显示
□ 排序规则正确（战斗力/稀有度/获得时间/部队容量）
□ 筛选功能正常
```

### 战车详情验证
```
□ 战车模型显示正确
□ 战车名称、品质显示正确
□ buff图标、描述显示正确
□ 槽位等级、限定兵种显示正确
□ 总容量、总战力计算正确
□ 满级预览正确
```

### 战车养成验证
```
□ 升级消耗正确扣除
□ 升级后等级/buff数值正确
□ 突破时材料切换正确
□ 满级后显示"已满级"
□ 满级后按钮消失
□ 资源不足时按钮置灰
□ 升级动画正确播放
```

### 战车战斗验证
```
□ 地图上战车模型正确
□ 行军动画正确播放
□ 白天/夜晚模型显示正常
□ 行军队列图标正确
□ 战斗时舱位buff生效
□ 承伤顺序正确
□ 战报英雄头像按舱位排序
□ 战斗日志按舱位显示
```

### 战车特性验证（反战车战车）
```
□ 攻击敌方战车时顺序为3→2→1
□ 被攻击时己方顺序为1→2→3
□ 敌方舱位有瞄准特效
□ AOE伤害在距离<X时触发
□ AOE伤害冷却回合数正确
□ 减速效果正确生效
□ 脱战2s后减速恢复
□ 战报日志显示特性技能
```

## 六、战车列表排序规则

| 排序类型 | 规则 |
|----------|------|
| 战斗力 | 从高到低，相同则按配置id从小到大 |
| 部队容量 | 从多到少，相同则按配置id从小到大 |
| 稀有度 | 从高到低，相同则按配置id从小到大 |
| 获得时间 | 从新到老，相同则按配置id从小到大 |
