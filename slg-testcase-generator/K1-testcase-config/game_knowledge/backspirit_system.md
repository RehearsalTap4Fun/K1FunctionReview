# 背后灵系统

> 提取自：红色英雄系统人工用例

---

## 一、系统概述

### 核心概念
- **背后灵**：一种特殊的参谋英雄
- **助战**：背后灵可以助战其他英雄，提供buff加成
- **附身**：背后灵附身在普通英雄上，共享天赋

### 基本规则
- 背后灵可以助战任意英雄
- 助战后提供助战技能buff
- 助战有冷却时间
- 取消助战需要等待冷却

## 二、与红色英雄的交互

### 交互场景清单

| 场景 | 描述 | 预期结果 |
|------|------|----------|
| 背后灵助战无共享新英雄 | 红色英雄未共享，背后灵助战它 | 正常助战，获得助战buff |
| 背后灵助战共享新英雄 | 红色英雄已共享A，背后灵助战红色英雄 | 红色英雄同时拥有专属+共享+助战buff |
| 已共享背后灵尝试助战 | 红色英雄共享背后灵A，A尝试助战其他英雄 | 列表不显示红色英雄 |
| 已助战背后灵尝试共享 | 背后灵A助战红色英雄，红色英雄尝试共享A | 无法选中，弹tips |
| 附身英雄被共享 | 背后灵A附身普通英雄B，红色英雄共享B | 可以共享，但不获得A的助战buff |
| 参谋英雄尝试共享 | 红色英雄尝试共享正在附身的参谋英雄 | 无法选中，弹tips |

### 复杂组合场景

```
场景：被助战+共享被助战英雄
1. 背后灵A助战普通英雄B
2. 背后灵C助战新英雄（红色）
3. 新英雄共享B英雄
预期：新英雄获得B共享技能+天赋+背后灵C助战buff
     新英雄不获得背后灵A的助战buff
```

```
场景：A附身红色B，C附身D，B共享D
1. 背后灵A附身红色英雄B
2. 背后灵C附身普通英雄D
3. B共享D
预期：
- 检查派出B后派兵列表表现
- 检查C能否取消助战
```

## 三、验证点清单

### 助战列表验证
```
□ 共享中的英雄不显示在助战列表
□ 选中共享中的英雄弹出tips
□ 助战冷却时间显示正确
□ 切换被助战英雄后冷却时间仍存在
```

### 共享列表验证
```
□ 正在助战的参谋不显示在共享列表
□ 选中正在助战的参谋弹出tips
□ 被附身的普通英雄可以共享
□ 附身的参谋英雄不能共享
```

### 战斗验证
```
□ 共享英雄助战red色英雄时，背后灵buff正常生效
□ 红色英雄不会获得被共享英雄的背后灵buff
□ 派出后背后灵无法取消助战（同线上）
```

### 名片显示验证
```
□ 英雄名片显示正确（同其他被助战英雄）
□ 派出后正确显示背后灵附身表现
□ 新英雄名片同时显示共享、双天赋、助战特效
```

## 四、Tips文案

| 场景 | Tips文案 |
|------|----------|
| 共享中无法助战 | 斗士参与同频中，无法进行助战操作 |
| 助战中无法共享 | 斗士参与助战中，无法进行同频操作 |
| 无法共享附身参谋 | 无法共享正在附身的参谋英雄 |
