## 系统概述

推币机玩法是一个小游戏类运营活动，核心玩法为：
1. 玩家投掷硬币到推币平台
2. 硬币被推落后攻击怪物
3. 获得积分和随机奖励
4. 触发特殊道具（问号宝箱、币堆）获得额外收益

## 入口HUD状态循环（必须验证）

### 状态切换逻辑
```
初始状态: 显示怪物刷新倒计时
    ↓ (等待x秒)
状态A: 显示怪物血条
    - 100% > 血量 > 20%: 黄色
    - 血量 ≤ 20%: 红色
    ↓ (等待x秒)
状态B: 显示怪物刷新倒计时
    ↓ (循环)
```

### 验证点
1. 切换间隔时间符合配置
2. 血条颜色区间正确
3. 特殊状态（刷新等待期）显示正确

## 首次进入动画状态机（必须验证）

### 动画阶段
```
阶段1: 隐藏所有UI，显示空白推币机
    ↓
阶段2: 推板静止
    ↓
阶段3: 怪物出场动画
    ↓
阶段4: 币堆升起动画
    ↓
阶段5: 震荡效果（x%硬币震落）
    ↓
阶段6: 显示所有UI，推板开始运动
```

### 关键验证
- 动画期间无法投币
- 配置参数：CoinPileNum（币堆银币数量）

## 投币操作模式（必须验证）

### 触发方式
| 方式 | 验证点 |
|------|--------|
| 单次点击 | 掉落位置、消耗免费次数 |
| 快速连续点击 | 触发长按提示 |
| 长按 | 连续掉落 |
| 滑动 | 不同位置连续掉落 |

### 资源优先级
```
免费次数 > 投币道具
```
- 免费次数用完后自动消耗道具
- 道具消耗完跳转礼包墙
- 投币中免费次数刷新时优先消耗免费

## 伤害计算公式（必须标注）

### 伤害公式
```
伤害 = 银币数量 * 银币基础伤害 * (100% + 评级加成 + 虚弱加成 + buff加成)
     + 金币数量 * 金币基础伤害 * (100% + 评级加成 + 虚弱加成 + buff加成)
```

### 怪物生命公式
```
初始生命 = 活跃玩家数量 * 初始生命系数
```

### 随机奖励数量
```
奖励数量 = 伤害值 / 10 （余数也算1个）
单次上限: n个（配置）
```

### 配置表
- 2182 RatingBonus: 评级加成
- 2182 InitialHP: 初始生命系数
- 2182 DamageReward: 奖励数量配置

掉落数量 → combo值 → 评级 → 颜色 → 伤害加成

4. 伤害加成与评级对应

### 配置表

## 怪物状态机（必须验证）

### 虚弱状态
```
触发条件: 血量 ≤ 20%
表现: 血条下方显示虚弱icon + 持续特效
效果: 攻击伤害增加虚弱加成
```

### 回血机制
```
触发条件: 血量 ≤ x%（配置血线）
触发概率: 符合配置
限制: 一轮只可触发一次
表现: 回血特效 + 血条恢复到y%
注意: 回血特效与虚弱特效同时存在
```

### 回血中被攻击
```
最终血量 = 回血后血量 - 本次攻击伤害
```

### 配置表
- 2182 Weakness: 虚弱加成
- 2182 HpReturn: 回血触发血线和概率

## 多玩家交互（必须验证）

### 实时刷新
- 在活动界面时看到他人攻击气泡
- 怪物血条实时减少
- 自己攻击不显示气泡

### 非实时刷新
- 离线后进入补播历史气泡
- 最多显示2条
- 按时间从远到近排序

### 同时攻击
- 伤害值为双方共同伤害
- 互相可见攻击气泡

### 同服/跨服区分
- 同服玩家头像可点击查看
- 跨服玩家头像无法查看，提示"玩家不同服"

## 保底机制（必须验证）

### 落空攻击积分
```
场景: 蓄力期间怪物被击杀/逃跑
积分 = 银币数量 * x + 金币数量 * y
```

### 活动结束清台
```
场景: 最后一只怪消失时台面有硬币/道具
流程: 清台动画 → 奖励汇总弹窗 → 折算积分
积分 = 金币攻击积分 + 银币攻击积分 + 币堆道具积分
```

### 配置表
- 2182 MissedAttackPoints: 落空攻击积分
- 2182 GuaranteedReward: 折算奖励配置

---

## 清台流程（必须验证）

### 触发
- 币堆道具被推落

### 流程
```
1. 弹出恭喜获得币堆弹窗
2. 空气墙出现，推落所有道具
3. 期间无法投币/点击功能按钮
4. 连续播放飘币+combo效果
5. 弹出问号宝箱奖励弹窗
6. 播放币堆升起动画
7. 恢复正常
```

### 数据处理
- 推落的硬币正确造成伤害
- 积分正确增加
- 进度溢出值计入下一轮
