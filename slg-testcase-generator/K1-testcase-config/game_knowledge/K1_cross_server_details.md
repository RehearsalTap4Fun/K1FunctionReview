## 二、KVK4 冰雪之星

### KVK4 地图结构
```
四角边境结构：
- 大地图左上、左下、右上、右下各有一个边境区域
- 每个边境区域被山体与外界隔断
- 每个边境区域内：
  - 2个公共建筑（己方入口，颜色与最近氏族登陆舱一致）
  - 1个建筑A·雪域探索站（区域正中央，中立不可攻击）
  - 4个建筑B·边境情报站（A两侧对称分布，自带阵营）
```

### KVK4 边境玩法（核心特色）

#### 1. 区域开放与进出
```
开放规则：
- 随天下大势解锁（第1天）
- 解锁后持续开放，无争夺期/保护期
- 不可迁城、不可铺旗
- 部队数量不限，机甲可进入

传送进入：
- 任务界面"前往边境"按钮 → 创建新部队 → 从最近己方公共建筑出发
- 选中已有部队进入：部队先回主城 → 恢复轻伤兵 → 补充同种同等级健康兵 → 从公共建筑出发
- 只能进入己方边境区域

传送退出：
- 点击返回按钮 → 部队行军到公共建筑 → 自动回主城 → 轻伤兵治愈 → 重伤兵进医院
- 选中边境外目标 → 部队先到公共建筑 → 从主城出发向目标行军 → 补兵

进入/离开提示：
- 进入边境弹出明显tips"部队已进入边境"
- 离开边境弹出默认tips

托管部队：
- 保姆操作号主部队传入：先回号主泉水圈 → 原样传入 → 不恢复重伤兵
- 保姆操作号主部队离开：先到公共建筑 → 原样传到号主泉水圈 → 不恢复重伤兵
```

#### 2. 战斗规则
```
- 有重伤、轻伤，无死亡
- 重伤比例比普通野外更低
- 健康兵量为0时，部队自动行军回公共建筑（死亡行军移速更高）
- 重伤兵直接进入医院
- 公共建筑 = 回城，进入时轻伤兵全部治愈
```

#### 3. 建筑A·雪域探索站
```
位置：区域正中央
阵营：中立不可攻击/占领
功能：
- 附近定时刷新野怪（雪狼）和探索点
- 刷新周期30分钟，每批N只
- 探索站周围半径X范围内不受寒冷影响
- 玩家可用探测道具手动触发刷怪/探索（50%概率各一种）
- 手动刷怪上限120只/区域，手动刷探索点上限20个/区域
```

#### 4. 建筑B·边境情报站
```
位置：A两侧对称分布，靠近己方2个，靠近敌方2个
阵营：自带阵营（靠近己方的归己方）
功能：
- 边境押镖起点
- R4/R5可召唤军团机甲
```

#### 5. 边境野怪系统
```
普通雪狼：
- 三种出现方式：①区域随机刷新（稀疏） ②手动召唤 ③A建筑附近定时刷新
- 等级：20/25/30/35（随时间解锁）
- 消耗体力，有掉落奖励
- 可使用5倍攻击
- 存活时间30分钟

分裂怪（特殊怪）：
- 与普通怪一起定时刷新
- 初始大怪 → 击杀后分裂2个中等怪 → 再分裂2个小怪 → 再分裂小小怪
- 消耗体力 = 各尺寸怪体力之和（开怪时一次性扣除）
- 中等怪/小怪主动攻击玩家
- 脱战后返回出生位置，返还未击杀怪的体力
- 不能使用5倍攻击
- 每击杀一只获得一份奖励

手动召唤刷怪事件：
- 使用探测道具在A建筑触发
- 每隔X秒刷新一批怪，持续5分钟
- 刷出的怪以召唤者为目标攻击
- 离开范围/死亡/时间到 → 停止刷新
- 怪无指定归属，其他人也可打
- 不扣体力，无掉落奖励，只完成任务
- 军团频道+全区域tips通知
```

#### 6. 探索点
```
- A建筑附近半径100米范围内随机刷新，每30分钟刷10个
- 点击弹窗可看说明和奖励预览
- 部队到达后读条：普通10秒，有普通机甲7秒，有KVK个人机甲3秒
- 读条完毕弹窗+邮件告知奖励
- 消耗体力
```

#### 7. 边境押镖
```
流程：
- 从己方B建筑出发 → 押运到最近敌方B建筑
- 部队在B建筑5000范围内可直接开始；范围外先行军到B建筑
- 镖车有加速按钮：速度+500%持续10秒，冷却15秒
- 中途有拦路小雪狼（不计入杀怪任务）
- 被打出镖车后镖车不消失，复活后可继续
- 押镖部队被打败后镖车继续走到终点
- 完成后邮件领取奖励（按镖车剩余血量评级）
- 每日次数上限，UTC零点重置
- 可召回放弃（次数返还）
- 同联盟/同军团可护卫

与原服/AC押镖互不影响：
- 边境押镖不消耗原服押镖次数
- 原服押镖不消耗边境押镖次数
```

#### 8. 极端天气
```
暴风雪：
- 随机时段产生，N个龙卷风组合
- 龙卷风半径5000，可移动
- 部队被卷到 → 冰冻在原地，无法行军
- 押镖部队不受影响，护卫部队会被冻
- 不会超出边境范围
- 每区域每天最多20次

冰刺：
- 随机时段产生，半径5000
- 踩到造成大量伤害
- 产生前有红圈预警2秒

滑冰区域：
- 不规则条形区域，从双方大门导向AB建筑
- 进入后大量移速加成
- 押镖路线避开滑冰区
- 滑冰区有更多冰刺

火盆：
- 固定坐标放置，从双方大门排到A建筑
- 5000范围内缓慢回复寒冷能量条
```

#### 9. 军团机甲（边境内）
```
召唤：R4/R5在B建筑或公共建筑召唤，整个军团限1个
泉水光环：半径R范围内脱战后持续回复轻伤兵 + 不受寒冷影响
攻击：可攻击敌对目标，对野怪只帮助提高效率不影响他人进度/体力/奖励
受击：常规机制，耐久度0销毁
```

#### 10. 地图随机事件（FATE）
```
触发条件：10个固定区域，双方玩家总数达到X时触发，或3小时无触发则随机触发

事件类型：
① 押镖事件：双方玩家<70%触发，圈内生成运输车+两个终点，5分钟后靠近哪方终点哪方获胜
② 建筑争夺事件：双方<70%触发，圈内生成建筑，参考高级火车GVG规则，5分钟后归属方获胜
③ 混战事件：双方<60%触发，杀敌获得更高积分，5分钟后直接结束
④ 探索事件：随机触发，圈内生成多个探索点，5分钟
⑤ 野怪事件：随机触发，圈内生成多个野怪，5分钟
```

### KVK5 地图结构

四圈层结构（从外到内）：

第一圈层（初始圈层）——活跃时间1-3天

- 红草原分布广泛，浅水洼较多
- 共6个区域，每个区域有收益和战斗建筑

- 野战圈开启时，树人进入竞速模式
- 两方树人同时向2级建筑行进，定时出现虚弱期可互相攻击
- 树人被造成特定伤害后行军速度减慢
- 率先到达2级建筑的树人获胜，拥有向最后圈层进发的权利

第四圈层（决赛圈）——活跃时间2-3天
- 有3级树人入驻建筑、一个wonder建筑

- 己方阵营领土与功能建筑接壤后，树人可入驻提供增益

### KVK5 阵营玩法（军团树人/巨像）
```
核心概念：
- 每个阵营拥有一个树人（巨像），随KVK阶段从边缘向中心移动
- 军团成员围绕树人进行捐献/养成，树人为军团提供增益/奖励
- 树人只能在中立建筑间移动
- 树人在某些中立建筑处参与战斗
- 树人不会消失/死亡

树人状态：
- 驻扎：基本状态，完成移动/脱离战斗后自动回到驻扎
- 移动：在中立建筑间移动，军团管理可操控
- 战斗：底层逻辑同普通部队（普通攻击、技能、反击）

树人驻扎规则：
- 只可在中立建筑旁驻扎（附属建筑位置，每个2-3个槽位）
- 已占领的中立建筑，树人驻扎时buff增益效果翻倍

树人战斗规则：
- 可被野战部队攻击，无法被集结
- 可攻击野战部队和集结部队，无法攻击中立建筑和其他树人
- 移动时防御力减半

树人经济技能：
- 消耗能量使用，有冷却时间
- 初始获得1个技能，后续随进入后续圈层自动解锁
- 技能提升在军团科技中进行
- 仅驻扎状态可释放，移动和战斗状态下无法释放
- 技能类型：符文掉落、树人矿点

树人光环：
- 附近一定范围内同军团成员享受buff加成
- 光环范围内可召唤战争树人
- 部分科技在进入对应区域后才生效（经济类光环）
```

```

- 定时定点开启，参与目标更清晰
- 强化阵营主体的特殊参与

玩法概述：
- 在常规野战区逻辑上增加阵营主体玩法（类似火车GVG）
- 野战区为矩形，两侧有关卡，内有两条并列跑道

- 每次乱斗期，关卡开放，树人移动速度翻倍，可被攻击
- 乱斗期间建筑可争夺占领，占领为己方树人提供移动加速
- 占领建筑、攻击树人/玩家可获得积分
- 每次乱斗期结束进行一次竞速结算

树人参赛资格：
- 有该野战区通行权限即可参与
- 根据阵营占领的关卡编号去对应轨道
- 多个关卡时优先前往编号更小的轨道
- 野战区开始时树人自动前往，玩家失去控制权
- 结束后树人自动返回之前建筑（有延迟配置），玩家可手动提前返回
- 移动到野战区过程中不可被攻击，返回途中可被攻击
- 野战区内能量不可被掠夺，树人不反击不攻击

胜负标准：
- 阵营胜负：获取积分更多的一方获胜
- 乱斗胜负：树人距终点较近的一方获胜
  - 胜者获得大量积分 + 限时buff
  - 获得野战区归属权（通行权）
  - 野战区刷新宝箱供胜者方玩家开启

结算奖励：
- 积分奖励：阵营积分排名奖励
- 阵营胜负：优胜奖励和参与奖励
- 野战区归属奖励：胜利阵营双向通行权，中立树人每天发胜利奖邮件
- 单个乱斗期奖励：刷新宝箱供拾取

地图设计：
- 3个野战区在三圈层内
- 两侧多个入口，特定时间开放
- 中间两条跑道（起点/终点），供树人竞速
- 跑道中间有建筑（占领提供移速加速）
- 跑道终点有核心建筑（更大的树人）
```

- 从地面到地下转场动画
- HUD：个人信息、能量仪、药水、地底开采证、CD、矿车队列、战役入口、地下科技、排行榜、帮派、聊天、搜索、邮件
- 地底开采证每日恢复x本、最大持有y本

地图映射：
- 地上建筑映射到地下

- 领土线映射正确
- 遗迹建筑映射（关卡不映射）

功能模块：
- 矿洞采集系统

### KVK5 建筑系统
```
建筑开启条件：
- 地图创建时一并刷新，中途不会有新建筑
- 随天下大势解锁，解锁后才可占领和激活功能

建筑功能5大类：
1. 增益型：提供增益buff（官职细分建筑 + 普通废墟建筑）
2. 关卡：提供连通性
3. Wonder：最终目标
4. 小门：区域连接
5. 登陆舱：起始点

建筑占领/驻防规则：
- 天下大势解锁后可攻击
- 同帮派/同军团不同帮派可驻防
- 同军团不同军团不能驻防/攻击/侦查
- 首次占领有保护期 + 首占弹窗
- 建筑弹窗：贴图、昵称、等级、野怪头像、技能图标、帮派收益、据点收益buff、推荐部队数量
```

### KVK5 积分排行系统
```
积分排行榜：
- 个人、帮派、军团三个排行
- 杀怪/采集/杀敌等行为三种排行相关
- 建旗/占领/升级建筑等帮派行为与军团相关
- 参与建旗时长/建筑升级贡献等个人行为只获个人积分
- 更换帮派时已加积分不变，新积分加到新帮派
- 每种行为有每日积分上限

积分来源：
- PVP战斗：野外击败敌方部队
- 打野：击败野怪
- 采集：采集资源
- 训练：训练部队
- 基因消耗：消耗基因资源
- 建筑占领：占领建筑
- 野战区：参与野战区

杀敌排行榜：
- 对其他军团T2及以上兵造成的重伤或死亡个数，排除机器人

结算发奖：
- 上榜最低积分1分
- 个人排行奖励：符合名次条件就发放
- 帮派排行奖励：按结算时所在帮派发奖，需有过积分贡献
- 军团排行榜奖励：需有过积分贡献
```
