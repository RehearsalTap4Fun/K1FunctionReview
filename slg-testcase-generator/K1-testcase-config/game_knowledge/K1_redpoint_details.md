## 一、红色英雄系统红点

### 未共享红点
```
触发：红色英雄未共享
消除：共享任意英雄
层级：
- 英雄入口HUD红点 +1
- 英雄展示界面A卡片红点 +1
- 英雄展示界面共享按钮 无数值红点
- 能力分享界面共享按钮 不显示红点
```

### 槽位升级红点
```
触发：有足够碎片可以升级槽位
消除：碎片消耗到无法再升级
层级：
- 英雄入口HUD红点 +1
- 英雄展示界面A卡片红点 +1
- 共享能力分页签红点 +1
- 升级技能按钮红点 +1
- 共享技能界面共享技能页签红点 +1
```

### 共享天赋红点
```
触发：获得激活点数
消除：使用完所有激活点数
层级：
- 英雄入口HUD红点 +x
- 英雄展示界面A卡片红点 +x
- 共享能力分页签红点 +x
- 升级天赋按钮红点 +x
```

### 成就奖励红点
```
触发：达成任务但未领取
消除：领取完所有已达成奖励
层级：
- 英雄卡片右上角数字红点 +1
- 奖励入口显示实心红点
- 已达成档位右上角实心红点
```

## 二、特殊情况验证

### 红点状态保持（红色英雄）
```
□ 玩家1有红点，玩家2没有红点
□ 重启客户端后：玩家1仍显示，玩家2不显示
□ 重启服务器后：状态不变
□ 跨UTC0点后：状态不变
```

### 切换共享不影响红点
```
□ 当前只有1个激活点数
□ 激活共享天赋树1后切换天赋树2
□ 红点状态不会改变
```
